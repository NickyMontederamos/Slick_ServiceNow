# Interactive Flow Map Builder Skill

A reusable skill for building polished standalone HTML flow maps, architecture command centers, workflow simulators, and agent orchestration visualizations.

## Included

- `SKILL.md`: activation criteria, workflow, acceptance criteria, and validation rules
- `assets/flow-map-template.html`: fully interactive ServiceNow agentic mission-control reference implementation
- `scripts/validate_flow_map.py`: offline structure, dependency, accessibility-marker, interaction-marker, and JavaScript syntax checks
- `references/design-system.md`: reusable visual and interaction guidance

## Quick validation

```bash
python scripts/validate_flow_map.py assets/flow-map-template.html
```
